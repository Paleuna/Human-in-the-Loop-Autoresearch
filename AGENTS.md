# Research agent instructions

For research work, read `GENERAL_REQUIREMENTS.md` first. It is the central scientific and engineering standard. The human supplies the direction in conversation or project files; use the project's existing tools and choose how to organize routine work.

`PLAN.md` and `REPORT.md` are readable examples while they contain placeholders. When a study has filled them in, read the current `PLAN.md` before implementation and use `REPORT.md` to return the complete evidence. Make the plan, substantive compute request, and results clear enough for human review. The human approves the plan and compute and makes the final scientific judgment, as described in `GENERAL_REQUIREMENTS.md`.

Note: agent should generate seperate 'plan' and 'report' folder to generate plan and report file, the `PLAN.md` and  `REPORT.md` are used as template, do not change it.

Before GPU or Slurm work, also read `gpu/GPU_REQUIREMENTS.md`. In a study with local copies of these files, use those copies.
